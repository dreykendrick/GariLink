# GariLink Owner Home V2

Owner Home is an operational workspace surface, not an analytics dashboard.

## Information hierarchy

1. Workspace name and Individual/Fleet context.
2. Shared workspace selector when multiple authorized workspaces exist.
3. Actionable setup attention.
4. Truthful workspace-scoped vehicle, publication, availability, request, and open-rental counts.
5. Vehicle and rental-request actions.

Individual mode stays compact. Fleet mode adds Busy, Unavailable, and Maintenance counts without introducing a second domain or application.

Zero workspace displays authorization/setup guidance. Zero vehicles explains the private-draft-to-publication path and directs the operator to Add vehicle. Loading and API failures retain context and use sanitized user-facing copy.

No revenue, earnings, payout, wallet, growth, utilization, or fabricated booking metric is shown. The fabricated Analytics route has been removed from routing and is unreachable in the production owner navigation.
